# Stack Tecnológica Oficial — OPEN//77 Life-Sim RP

| Camada | Tecnologia | Versão | Papel no Projeto | Invariante Técnico |
| :--- | :--- | :--- | :--- | :--- |
| **Servidor Host** | Linux x64 / Windows (.NET 8 Runtime) | .NET 8 / Build 2.31.21+op77.124 (Protocolo 1.44) | Binário dedicado OPEN//77; gerenciamento de conexões assíncronas, routing buckets e alta densidade de rede. | Licenciado à conta Master; Warden para administração; RCON CLI; métricas Prometheus. |
| **Scripting / Lógica** | Lua 5.4 isolado por recurso (Client & Server VMs) | Lua 5.4 | Regras de gameplay, economia, biometria, eventos e controllers. Cada recurso possui VM própria. | Server-authoritative estrito. Comunicação entre recursos via host-wide event bus (`TriggerEvent`), State Bags (`Open77.state`) e exports declarativos. |
| **Cache em Memória** | CacheService (Tabelas Lua in-memory) | Nativo Lua 5.4 | Estado volátil de alta frequência: biometria, sessões ativas, calor de ciberware, coordenadas temporárias. | Descarregado via Write-Behind em lotes a cada 5m, no disconnect e no resource stop. |
| **Persistência Relacional** | MariaDB 10.4+ / MySQL 8 (InnoDB) | MariaDB / MySQL 8 | Inventários, carteiras monetárias, escrituras de imóveis, histórico financeiro e colunas `JSON`. | Bridge SQL assíncrona nativa OPEN//77 (`database.access`) via `MySqlConnector`. Transações com locks explícitos (`SELECT ... FOR UPDATE`). |
| **Front-End / NUI** | Vanilla HTML5 + CSS3 (Design System Kiroshi) + ES6+ JS | Web Standards | Interfaces diegéticas in-game (HUD Kiroshi, terminais, ATMs, vending, moradia, radar). | Renderizado no motor CEF (Chromium Embedded Framework) out-of-process. Cantoneiras L-brackets, recortes angulares `clip-path: polygon()`, glassmorphism `blur(16px)`, `clamp()` multi-resolução e Web Audio API para síntese sonora. Zero VDOM / Zero React. |
| **Áudio Espacial** | `open-voice` | Nativo OPEN//77 | Comunicação de voz 3D com oclusão geométrica por paredes e efeitos de rádio/holocall. | Configurado nativamente na plataforma via WebRTC / Proximity. |
| **Ferramentas de IA/IDE** | `@open2077/mcp` (Devkit) | 2.31.21+op77.124 | 27 ferramentas MCP para busca de nativas, validação de recursos e documentação interativa. | Suporte a Antigravity IDE, Claude Code, Cursor e Gemini CLI. Tipagens em `open77-client.d.lua` e `open77-server.d.lua`. |

> **Nota de Compatibilidade:** A bridge nativa do OPEN//77 suporta **MySQL e MariaDB**. O plano inicial previa PostgreSQL e Redis externo; a arquitetura atual utiliza MariaDB 10.4+ com tabelas InnoDB e CacheService em memória integrado no kernel Lua com estratégia Write-Behind, garantindo máxima performance sem dependências externas incompatíveis.
